# 页面编辑模式设计

状态：第一阶段已实现，2026-10-08。Web 浏览器已验证；Tauri/PWA 原生文件流程尚待实机验收。

## 入口与布局

在现有模式切换中增加「页面」，与「注释」「表单」并列。模式选择位于顶部右侧固定操作区，切换模式时保持位置稳定。进入后，主工作区切换为整屏缩略图网格；保留文档标签、撤销/重做与保存入口。选择状态由各文档独立保存。

- 每张缩略图底部始终显示页码、顺时针/逆时针旋转、复制和删除。
- 点击页面默认单选；Ctrl/Cmd 点击增减选择，Shift 连续选择，Ctrl/Cmd+Shift 追加范围。右键菜单支持只选此页、添加/取消选择、连续选择到此页、全选及清除选择。
- 页面选择与拖动的点击范围贴合纸张；高亮框与纸张之间保留 3px 间距，外侧留白不触发页面选择或拖动。
- 页面操作统一放在顶部主工具栏中间，与注释、表单模式沿用相同的图标按钮样式；导入 PDF、空白页和共用旋转、复制、删除始终显示，无选择时共用操作置灰。选择数量和全选控件独立放在左侧，不作为工具或收进「更多」。复选框始终显示，部分选择时呈半选状态；未选满时点击全选，全选后点击清除选择。窄屏复用响应式工具栏的「更多」面板，不再增加第二排工具栏或状态行。单击其他页面恢复单选，点击网格空白或 Escape 清除选择。
- 「完成」位于顶部右侧、保存左边，复用其他模式的右侧栏按钮位置；返回之前的阅读模式，保留未保存的编辑。写入文件仍使用现有「保存」。

页面身份保持稳定，页码随排序变化。缩略图缩放与阅读缩放独立，由各文档的 `pageThumbnailScale` 保存；Ctrl/Cmd + 滚轮、顶部加减按钮和比例菜单共同调整 50%–200% 的缩略图大小，选择 100% 恢复默认大小。切换编辑模式或标签页不会改写另一种缩放，也不产生编辑历史。

网格根据缩略图大小和容器宽度自动调整列数和行高，窄屏放大时可变成单列。缩放或调整窗口大小时保留当前浏览位置；虚拟滚动、拖动浮层和文件插入标记使用相同布局尺寸。缩小后页码和操作按钮分两行显示，保持按钮可用。

拿起页面时通过网格容器样式隐藏选择高亮，仅更新移动中的卡片；右键菜单打开时才计算范围选择是否可用。排序提交复用位置和内容未变化的页面及控件对象，避免放下时整片网格重新渲染，并保留原有缩略图节点与缓存。

## 选择与操作规则

- 页面上的编辑按钮只作用于该页；顶部批量按钮作用于全部选中页。
- Ctrl/Cmd+A 全选，输入框内维持文本全选；Escape 优先取消拖动或关闭菜单，再取消选择。
- 双击页面进入该页阅读；退出时恢复阅读位置、缩放和侧栏状态。
- 用 dnd-kit 的排序、拖动浮层和动画实现网格拖动。多选页作为连续块移动，保持原文档顺序。排序只在松手时提交一次，Escape 取消不写入历史。
- 多页拖动用最多三张缩略图叠放并显示总数，以拿起的页面为前景。每张叠放页保留自身尺寸、方向和比例，不套用前景页的白色底框。浮层不显示边框或选择高亮；松手时选中页从叠放位置展开到各自的落点，取消时回到原位置。落位动画只复用可见页的缩略图，不额外渲染 PDF；动画期间隐藏对应实页，完成后恢复，避免重影。占位页立即定位，周围页面动画让位，避免快速松手时落点偏移。启用减少动态效果时直接落位。
- 单页和多页共用落位交接：动画结束前隐藏落点上的真实页面，完成后同帧恢复完整透明度，避免提前显示或重影。拖回原位和取消拖动也遵循相同规则。
- 缩略图支持鼠标拖动、触屏长按拖动、键盘空格启动/结束与方向键排序。普通触屏滑动仍可滚动；靠近网格边缘自动滚动。
- 移除独立移动页面对话框，统一拖动排序。
- 共用操作适用于单页或多页选择，无选择时禁用；无选择时插入默认追加到末尾，有选择时默认插在所选页之后。
- 每次批量操作是一条撤销记录。删除后选择原位置的下一页，没有下一页则选上一页。
- 文档至少保留一页。普通删除直接执行并提供撤销；禁止删除全部页面。

| 操作        | 交互                                                             | 结果                                       |
| ----------- | ---------------------------------------------------------------- | ------------------------------------------ |
| 导入 PDF 页 | 选择文件或直接拖入网格，预览并勾选页码，也可输入 `1-5, 8, 10-12` | 按源文档顺序插入，保持原页尺寸与方向       |
| 增加空白页  | 尺寸、方向、数量、插入位置；默认同所选页尺寸，无选择时 A4        | 插入真正的空白 PDF 页，不生成白色图片      |
| 复制页      | 卡片按钮或顶部批量操作，默认插在最后一张操作页之后               | 保留内容、注释与表单；副本使用新身份       |
| 删除页      | 卡片按钮或顶部批量操作                                           | 一并删除该页注释与表单控件，撤销可完整恢复 |
| 旋转页      | 卡片或顶部直接点击顺时针/逆时针 90°                              | 改变页面实际方向，保存到 PDF               |
| 排序        | 拖动单页或选中页组                                               | 更新页面顺序，注释、表单和选择跟随原页     |

点击「导入 PDF」直接打开文件选择器。选择或拖入文件后，复用打开 PDF 的 toast 显示读取、解析状态；成功后才打开选页对话框并渲染预览。读取或解析失败只显示错误 toast，不打开导入弹窗；空文件提示文件名及 0 字节。取消文件选择不打开弹窗，退出页面模式会取消加载并清理 toast。导入/空白页的插入位置使用 UI 下拉组件，支持文档开头、末尾、输入指定页之前/之后；仅在实际有选择时显示所选页之前/之后。拖入文件时显示页间插入线，弹窗默认保留落点；确认前不改变文档。

导入弹窗只展示已选文件的名称和页数，不再提供重复的选文件入口。桌面端左侧设置页码范围和插入位置，右侧连续滚动预览；预览按可见行虚拟渲染，不再分页。窄屏上下排列，内容可滚动，取消和导入按钮固定在底部。

空白页弹窗采用相同的左侧设置、右侧预览布局；纵向/横向直接切换，预览同步显示比例和毫米尺寸。页数和目标页码复用数字输入组件；同所选页尺寸默认沿用该页方向，底部固定取消和添加按钮。

选页范围复用整页翻译的 `src/utils/pageRange.ts` 解析与格式化工具。预览中的 Shift 点击支持连续选择，滚动后仍保留选择起点；连续选择自动合并为范围文本。空选择或错误范围禁用确定按钮，翻译原有的空输入表示全部页语义保持不变。

导入先在临时会话中完成文件解锁、页码检查与所选页资源准备，成功后一次性加入当前文档；取消或失败不留下半次操作。一次拖入多个 PDF 时依次打开选页对话框，下一文件接在前一文件的导入页后；每个文件单独记录撤销，取消终止剩余队列。

加密来源复用打开 PDF 的密码对话框和重试流程：密码正确且权限允许后才显示导入预览，错误密码可重新输入。取消密码输入不显示错误 toast；退出加载会终止等待并关闭对应密码框。来源密码随原始字节保留在文档 source pool，供插入后的渲染与保存复用，不改变目标文档的密码。

## 阅读旋转与页面旋转

现有底部下拉菜单中的阅读旋转继续保持临时、整份文档生效、不影响保存。

页面模式显示实际编辑方向，暂不叠加阅读旋转。离开页面模式后恢复之前的阅读旋转值。两种旋转相互独立：

```text
实际页面方向 = 原 PDF 页方向 + 页面编辑旋转
阅读显示方向 = 实际页面方向 + 临时阅读旋转
```

页面旋转产生脏状态、支持撤销；「恢复原始方向」仍只清除临时阅读旋转。页面编辑的旋转使用撤销恢复，不共用这个按钮。

## 文档模型

`PageData` 在第一次结构编辑时加入稳定 `id`，`source` 记录源文档、源页和复制批次，`blank` 标识空白页。`pageIndex` 始终表示当前显示顺序，`rotationDelta` 表示实际编辑旋转。

实现入口：

- `src/components/page-editor/`：模式界面、虚拟网格、导入预览。
- `src/store/slices/pageEditingSlice.ts`：页面事务、关联对象映射。
- `src/services/pdfService/lib/assemblePages.ts`：保存时组装页面及 AcroForm。
- `src/services/pdfService/pdfWorkerService.ts`：逻辑页到原文件页的渲染路由。

- 原始文件保存在文档独立的 source pool 中，包含源字节、源页几何信息及渲染会话。导入来源按需加载，不为每张页重复存储 PDF 字节。
- 页面选择使用稳定 `id`。现有表单、注释与保留对象继续使用 `pageIndex`；每次结构事务按页面身份同步重映射索引，避免改动既有控件坐标协议。
- 原 PDF 对象引用通过所在页的 `source.documentId` 和 `copyGroup` 分区，保存时建立各分区的对象映射；不同文件的同号对象以及多份副本不会混用。
- 复制页分配新 `pageId`，深复制可编辑对象并分配新控件 ID。原内容资源可以复用，编辑状态必须独立。
- 控件几何保持在源页坐标系中，旋转时不反复改写坐标。渲染和指针输入使用变换适配，保存时通过源视口及最终页面方向转换。

## 渲染、历史与保存

### 渲染

复用现有虚拟化、缩略图与分块渲染。渲染请求携带源文档和源页身份；缓存键包含源身份、页面旋转和缩放。重排只改变布局，旋转只更新受影响页，禁止每次操作都重新生成或重新打开整份 PDF。

保留不同页面的 MediaBox、CropBox、UserUnit 和原始 Rotate。对新旋转角度继续沿用当前画布生命周期保护，避免复用已转移的 OffscreenCanvas。

### 历史

`HistorySnapshot` 已包含页面结构及来源池。页面操作同时提交结构、关联对象、权限脏状态和一条历史记录，撤销/重做作为同一个事务恢复。

历史只保存不可变结构和资源引用，不把整份 PDF 字节复制进每个快照。资源回收同时检查当前文档、撤销/重做记录及正在进行的保存；关闭文档后统一释放。

### 保存

导出时捕获该文档的完整修订快照，按页面清单组装输出 PDF，再建立「源页实例/对象 → 输出页/对象」映射，以此写入或更新注释、表单和引用。保存中的后续编辑仍保持未保存状态；完成回调不得更新另一个标签页。

原 source pool 保持稳定，不直接拿输出对象编号覆盖源引用。若以后增加保存后的 source rebase，必须连同历史和引用映射单独设计。

关键兼容要求：

- **表单结构**：复制控件所在页不等于复制完整 AcroForm。需重建字段树、widget 的 Parent/P 引用、字体资源和外观。
- **字段重名**：导入或复制时默认给新增字段生成不冲突的名称。一次复制操作内原本属于同一字段或单选组的控件维持分组；副本与原件互不联动。
- **注释**：复制和保存应保留支持编辑的注释及暂不支持编辑的源注释，并重建回复、弹窗等对象关系。
- **内部跳转**：同文档重排以稳定身份保持书签与链接目标。删除目标页时清理失效跳转；复制页的内部目标优先映射到本批副本，否则指向保留的原页。导入未包含的目标页时不制造错误页码跳转。
- **限制权限**：复用现有权限策略，将 `canAssemble` 接入页面操作检查和保存脏状态，确保受限文档的页面操作与保存行为一致。
- **运行时派生状态**：同步更新当前页、缩略图、搜索定位、目录、翻译定位和页面跳转；清理已删除页的异步任务。

### 已验证的实现风险

本仓库使用的 `@cantoo/pdf-lib` 2.5.3，在本地创建含一个文本字段的 PDF，执行 `copyPages` 后保存并重新打开，结果为：一页、一个页面 widget、零个 AcroForm 字段。因此不能仅拼接页数组就宣布导入/复制表单完成。

## 阶段范围

1. **已实现：组装与回读**：用多种原生方向、不同页尺寸、带表单和注释的 PDF 建立夹具，验证复制/导入后的字段树、对象映射和编辑能力。
2. **已实现：稳定页面模型与结构事务**：引入 pageId/source pool、统一历史和保存快照，接入权限与文档 runtime 生命周期。
3. **已实现：页面模式与本文件操作**：网格、多选、排序、旋转、删除、空白页、复制页，完成保存回读闭环。
4. **已实现：PDF 导入**：页码范围、预览连续选择、解锁、字段冲突处理、取消和失败回滚；支持拖入多个文件依次选页。
5. **后续扩展**：提取页面、替换页面、按页拆分；裁剪、页码与页眉页脚另行设计，避免第一版过重。

## 验收

- 原始 Rotate 为 0/90/180/270 的页面分别操作，编辑后注释和表单位置不偏移。
- 混合尺寸、CropBox 偏移与非默认 UserUnit 的 PDF，保存回读后尺寸、文字和控件正确。
- 复制、重排、旋转、删除交错进行，逐步撤销/重做能恢复内容与对象关系。
- 复制页里的字段可独立填写；同一批副本里的单选组仍互斥；导入重名字段不改变原字段。
- 文本、勾选、单选、下拉和签名外观，以及只读和最大长度约束正确保留。
- 页面编辑旋转写入输出，临时阅读旋转不写入；保存途中继续编辑不会误清除脏状态。
- 导入取消、错误页码、解锁失败不改变当前文档；最后一页保护、多标签隔离正常。
- 大文件优先渲染可见缩略图，再按页序预热；拖放期间继续渲染，持续拖动和旋转不重建全文档，内存不随撤销无限增长。
- 分别验证 Chromium Web、PWA 文件重开和 Tauri 原生打开/保存，不能用 Web 构建结果替代桌面验证。
