# Sample document

`reading-notes.pdf` is a generated, three-page sample for checking the real Legir editor. It contains reading notes, an example annotation, and fillable review fields. It contains no user documents or credentials.

The landing page no longer uses captured editor images. Its interactive HTML counterpart lives in `www/src/components/workspace-demo/` and does not load this PDF, a PDF worker, or the real editor runtime.
